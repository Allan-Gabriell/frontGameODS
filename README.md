# Jogo da Memória - ODS Match

Este projeto é um Jogo da Memória temático sobre os Objetivos de Desenvolvimento Sustentável (ODS), desenvolvido para a disciplina de Teste de Software.

## 🎯 Sobre o Jogo

O Jogo da Memória ODS é uma aplicação web interativa onde o jogador precisa encontrar pares de cartas. Cada carta representa um dos Objetivos de Desenvolvimento Sustentável da ONU. O objetivo é virar duas cartas por vez e encontrar todos os pares correspondentes no menor tempo possível.

## 🚀 Como Executar o Projeto

Para executar o projeto em sua máquina local, siga os passos abaixo.

### Pré-requisitos

-   [Node.js](https://nodejs.org/en/) (versão 16 ou superior)
-   [Yarn](https://yarnpkg.com/) ou [npm](https://www.npmjs.com/)

### Passos

1.  **Clone o repositório:**
    ```bash
    git clone <https://github.com/Allan-Gabriell/frontGameODS.git>
    cd MemoryGame
    ```

2.  **Instale as dependências:**
    ```bash
    npm install
    ```

3.  **Inicie a aplicação:**
    ```bash
    npm start ou npm run dev
    ```

4.  Abra seu navegador e acesse `http://localhost:5173`.
